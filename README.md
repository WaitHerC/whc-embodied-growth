## 二、我理解的具身智能

让 AI 拥有物理身体，通过 **"感知 → 决策 → 控制"** 闭环与真实世界交互。

与传统 AI 的本质区别：

| 维度 | 传统 AI | 具身智能 |
|------|---------|----------|
| 输入 | 静态数据集 | 实时、带噪声的传感器流 |
| 约束 | 算力与数据 | 物理约束 + 实时性 + 不确定性 |
| 输出 | 文本/图像/预测 | 必须落到动作的力矩与轨迹 |
| 验证 | 离线指标 | 必须在真实世界中成功执行 |

一句话：**传统 AI 在屏幕里思考，具身智能要在物理世界里承担后果。**

## 四、能力差距：目标值 vs 当前值

不量化就无法追踪。下表是我对照企业招聘 JD 做的自我评估：

| 能力项 | 目标值（岗位要求） | 当前值（2026.10） |

## 七、踩坑与反思

### 坑 1：以为"跑通 Demo"就是"会用大模型"

**过程**：本地部署完成后，调用 API 跑 Demo 一切顺利，我一度认为自己已经掌握了。
等到想压缩显存占用、提升推理速度时，彻底卡住 ——
因为不懂底层原理，只能在参数表面反复试错。

**认知升级**：停留在"会用"层面，解决不了具身智能里
"从感知到动作"的闭环问题。

**调整动作**：
从"会用"转向"懂原理、能落地"，
把数学基础与 ROS 仿真提为最优先补齐项。
