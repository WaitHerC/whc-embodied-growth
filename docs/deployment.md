## 四、踩的坑

### 坑 1：下载过高版本模型
- **现象**：Error:500 报错
- **排查**：显存不够
- **解决**：下载低版本模型

## 五、这次经历给我的认知升级

跑通 Demo 只是"会用"，不等于"懂"。
当我想压缩显存、提升推理速度时彻底卡住 ——
因为我只懂调参数，不懂底层原理。

这让我意识到：具身智能要的是
**"感知 → 决策 → 控制"的完整闭环能力**，
停留在调用 API 的层面远远不够。
所以我后面把数学基础和 ROS 仿真提为最优先补齐项。
